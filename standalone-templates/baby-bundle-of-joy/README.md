# A Little Bundle of Joy — baby celebration invitation

A standalone animated invitation (Baby & Family occasion) for WedVibe. One HTML file with
inline CSS and vanilla JavaScript, plus an original SVG illustration family in `assets/`.

## Run it

- Double-click `index.html` (works straight from the file system), or
- serve the folder, e.g. `npx serve standalone-templates/baby-bundle-of-joy`, and open the URL.
  Serving it is better for testing "Copy Link": browsers only allow clipboard access on
  `https://` or `localhost` pages (on `file://` it falls back to the older copy command).

## Change the details

Everything editable is in **one object at the top of the `<script>` in `index.html`**:
`invitationData`. Nothing else needs touching:

| Field | Used for |
| --- | --- |
| `babyTitle`, `babyName` | "Baby Aarav" everywhere (opening, card, closing, share text, page title) |
| `parentsNames`, `grandparentsNames` | Card, family panel, message signature (`grandparentsNames: ""` hides the row) |
| `functionTitle`, `heading`, `subtitle`, `inviteLine`, … | All wording, including the tap hint and closing line |
| `eventDate`, `eventEndDate` | Local time at the venue (`YYYY-MM-DDTHH:mm:ss`) |
| `utcOffset`, `timeZone` | Venue time zone, so the countdown and calendar are right for guests anywhere |
| `venueName`, `venueAddress`, `googleMapsUrl` | Venue panel and Get Directions (empty URL = Maps search for the venue) |
| `events[]` | Timeline — any number of `{ time, title, description, icon }` (icons: blessing, party, lunch, cake, music, gift, camera) |
| `galleryImages[]` | Photos — strings or `{ src, caption }`; empty = the built-in illustrations; a photo that fails to load falls back to an illustration |
| `shareMessage` | Optional WhatsApp text; `{url}` is replaced with the page link |

Colours, fonts, spacing, radii and timings are CSS variables in `:root` at the top of the file.

## Assets (all original, in `assets/`)

`baby-hero.svg`, `baby-peek.svg`, `teddy-bear.svg`, `fluffy-cloud.svg`,
`pastel-balloon-{pink,blue,yellow,mint,lavender}.svg` (with string, decorative),
`balloon-body-{pink,blue,yellow,mint,lavender}.svg` (no string, the tappable balloons),
`butterfly-{pink,blue}.svg`, `star-{gold,pink,lavender,blue}.svg`, `heart-{pink,lavender}.svg`,
`baby-gallery-{1,2,3,4}.svg`, `flower-{pink,lavender}.svg`.

They are vector illustrations generated by `tools/generate-assets.cjs` (shared baby head,
swaddle, cloud and teddy parts keep every picture consistent). Edit that script and run
`node tools/generate-assets.cjs` to restyle them. Raster 3D renders (e.g. `baby-hero.webp`)
were not produced in this environment; to use them later, drop the files into `assets/` and
change the `src` of the matching `<img>`. Every character and decoration on the page is one of these
images (only the balloon strings and small UI icons are drawn in code).

## External resources

Only Google Fonts (Fredoka, Dancing Script, Nunito). Without internet the page falls back to
system fonts. No frameworks or other libraries.

## Behaviour notes

- Sound is off by default; the speaker button turns on a soft pop and chime (Web Audio, no files).
- Every balloon is its own button and pops independently (burst ring, falling string, confetti).
  The first pop opens the invitation; the others stay up and can still be popped. Tapping the same
  balloon again does nothing. Replay restores all four.
- Low-end phones: no CSS shadow/blur filters on moving elements (shadows are baked into the SVGs),
  sections pause their animations while off screen, and phones with ≤4 CPU cores or ≤3 GB memory
  get half the confetti and fewer stars/hearts.
- `prefers-reduced-motion`: no floating, parallax or confetti; content fades in plainly.
- The countdown switches to "happening now" during the event and a thank-you after it ends.

## Moving it into the WedVibe app later

`invitationData` matches the shape of WedVibe's `InvitationData` closely (couple fields map to
baby/parents), so the page can become a React template component: the render functions
(`updateDetails`, `renderEvents`, `renderGallery`, `startCountdown`, `renderBalloons`) map to
components, and the CSS can move into the component's `<style>` block like the other templates.
Set its occasion to "Baby & Family" in Admin → Templates once it is registered.
